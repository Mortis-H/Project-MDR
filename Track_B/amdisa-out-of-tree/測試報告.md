## 🐛 問題與修正

### 問題 1: Passes.h.inc 位置錯誤

**症狀**: 編譯錯誤 - 找不到 `AMDISA/Passes.h.inc`

**原因**: TableGen 將 Pass 標頭檔生成在錯誤的子目錄 (`IR/` 而非 `AMDISA/`)

**修正**: 
- 將 Pass TableGen 配置從 `include/AMDISA/IR/CMakeLists.txt` 移至 `include/AMDISA/CMakeLists.txt`
- 確保生成的檔案在正確的位置

**狀態**: ✅ 已修正

### 問題 2: MCContext ObjectFileInfo 未設置

**症狀**: Segmentation fault 在執行時

**原因**: `MCContext` 創建後未設置 `ObjectFileInfo`，導致空指標解引用

**修正**:
```cpp
// 在 parse_utils.cpp 中新增
Ctx.setObjectFileInfo(MOFI.get());
```

**狀態**: ✅ 已修正

### 問題 3: Deprecated API 警告

**症狀**: 6 個編譯警告關於 deprecated API

**影響**: 僅警告，不影響功能

**警告列表**:
1. `OpBuilder::create` → 建議使用 `OpTy::create`
2. `TargetRegistry::lookupTarget` → 建議使用接受 Triple 的重載版本
3. `Target::createMCRegInfo` → 建議使用接受 Triple 的重載版本

**狀態**: ⚠️ 可選修正 (不影響功能)
